Install Glosside in Chrome

  1. Open Chrome’s Extensions page

    Copy the address below, paste it into Chrome’s address bar, and press Enter.

  2. Turn on Developer mode in the top right

    Extensions Developer mode
    Load unpacked Pack extension

  3. Click Load unpacked

    Select this folder in the file picker.

    On Mac, press ⌘ + Shift + G in the picker to paste the path.

    Glosside settings open after Chrome loads the extension for the first time.

Already loaded Glosside?

Click Reload (↻) on the Glosside card, then refresh any pages you want to translate.
