Download `glosside-chrome.zip`, or use `install.sh` (macOS/Linux) or `install.ps1` (Windows) to download, verify, and extract it automatically. The same ZIP works on all supported desktop platforms. See the [installation instructions](https://github.com/rice8y/glosside#installation).

Requires Chrome 151 or later. After extraction, open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. Select the directory printed by the installer, or the `glosside` folder from the ZIP. For updates, run the installer again, click **Reload** on Glosside, and reload your open pages.

Model weights are downloaded separately in Glosside's settings (about 573 MB), after you review and accept the model license.
